## XP Guidance

**Load path:** `XP_Guidance`  
Award via `award_xp` **outside combat** when thresholds / scenes resolve.

| Milestone | XP |
|-----------|----|
| Prologue (Ch1) | 25 |
| Evaine + Aldric quest | 25 |
| Dragon scale obtained | 50 |
| Orc bandits | 25 |
| Mercury obtained | 50 |
| Undead in mine | 50 |
| Mandrake obtained | 50 |
| Elven rangers (if fought/resolved) | 25 |
| Ritual success (all pure) bonus | 50 |
| **Full run (all pure)** | **~350** |

Early end (time-out / backfire): award only what was completed. Level-up only outside battle when XP hits next threshold (100 / 250 / …).
