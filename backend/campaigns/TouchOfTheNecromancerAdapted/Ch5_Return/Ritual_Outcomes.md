## Ch5 — Ritual Outcomes

**Level:** 1–3 · **Location:** `loc-aldric-tower`  
**Load path:** `Ch5_Return/Ritual_Outcomes`

### Preconditions

- **All three** ingredients required. Fewer than three: Aldric refuses; clock continues — send PC back to unfinished legs.
- If counter is **0** (or would go ≤0): skip ritual → **time-out** ending.

### Ritual

Aldric performs the counter-ritual. Do **not** foreshadow impure backfire. Resolve:

| Condition | Outcome | Story element |
|-----------|---------|---------------|
| Counter 0 before all three | Aldric cannot help; Sera becomes a lich and escapes; campaign ends | **ev5-time-out** |
| All three **pure** | Sera restored; hefty bill (pay later); bonus XP | **ev5-success** |
| Any ingredient **impure** | Curse transfers to **PC**; Sera saved; that night PC becomes lich / lost. Prompt save of **pre-lich** character copy | **ev5-backfire** |

### Purity reference

- **Scale:** dragon (pure) vs lizardman/substitute (impure)
- **Mercury:** pure vs impure ore/vial
- **Mandrake:** Mara or correct forage (pure) vs wrong/wilted (impure)

### Story elements

- **ev5-ritual** — Spell cast.
- **ev5-time-out** / **ev5-success** / **ev5-backfire** — endings above.
- Malachara revenge = **future campaign hook only**.

### XP

- Ritual success (all pure) bonus: **50 XP**
- If campaign ends early (time-out / backfire): award XP for completed legs only.
- Target full run ~**350 XP** (see `XP_Guidance`).
